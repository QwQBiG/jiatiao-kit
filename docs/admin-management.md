# 后台管理

运行 `npm start` 后，打开终端输出的「管理页面」。本地预览会以主管身份进入 `/admin/` 并生成一名演示学生，重启后数据会重置。部署到自己的站点后，主管和成员通过 Cloudflare Access 登录。[部署与登录配置](cloudflare.md)

## 从一条请假记录开始

1. 进入「学生记录」，按姓名、学号或班级搜索。在演示学生一行点「新增请假」。要建立另一名虚构学生的档案和首条请假，点页面上方的「新增学生」。
2. 填写「本次请假」中带星号的字段，结束时间须晚于开始时间。如需附件，在「附件图片（选填）」中点「添加图片」。每条记录最多选 3 张 JPG、PNG 或 WebP，单张原图上限 10 MiB。浏览器先生成 JPEG 小图，后台只保存小图。保存后，有图的记录会在分享页显示附件。
3. 点「生成新链接」。回到学生列表点「复制链接」，把复制的地址粘贴到新窗口，查看该学生最新一条记录。之后可点「编辑最新记录」，改完点「保存修改」。重新打开原链接即可看到更新。

## 查历史与停用链接

点学生姓名下方的「查看 N 条记录」，按请假起止时间找到需要的那条，再点「复制链接」或「停用此条链接」。用「恢复此条链接」可让同一地址重新可用。每名学生保留最近 100 条请假，超出时会移除最早的记录及其链接。

## 成员权限与操作记录

主管先建立学生档案和首条记录，再进入「成员权限」→「绑定成员」，填写姓名、登录邮箱，选择绑定学号并点「保存绑定」。该邮箱还须获准通过站点的 Access 登录策略。

成员登录后可用「新增本人请假」或「修改本人内容」维护绑定学号的请假时间、类型、原因、地点、离校选项和附件。身份资料、审批人及状态由主管维护。主管可对成员使用「停用登录」或「恢复登录」；要收回某条假条的访问权限，请在那条记录上停用链接。

主管可在「操作记录」查看最近 100 项变更，包括操作时间、操作类型和操作者邮箱。
