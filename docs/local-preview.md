# 在自己的电脑上试用

安装 Node.js 22.13 或更高版本，在仓库根目录运行：

```sh
npm start
```

本地演示仅使用 Node.js 内置模块，可以直接启动。终端会给出三个地址：

- `/` 是项目入口。
- `/demo` 打开本次启动生成的虚构假条。每次启动都会生成新的分享编号。
- `/admin/` 以本地演示管理员身份打开管理界面，可修改记录、添加缩略附件，或停用领取过的分享链接。

在管理页停用演示记录后，再次打开同一份假条可以查看停用状态。恢复后用原链接重新访问。按 Ctrl+C 停止服务。演示数据存储在内存，进程退出时清空。

服务只监听 `127.0.0.1`。如默认端口已被占用，可用环境变量 `PORT` 指定其他端口。生产部署使用独立的数据库和管理员登录。

运行验证：

```sh
npm test
```
